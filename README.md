# 3D Gaussian Splatting 浏览器

面向数字资产人员的高斯泼溅重建结果检查与展示工具。使用 TypeScript + React 19 +
Three.js（相机/控制器）+ 原生 WebGL2（高斯绘制），内置吉他场景并支持打开
本地 `.splat` 文件；同时提供镜头关键帧编排、时间轴预览与 1280×720
VP8/WebM 离线成片导出。

## 启动

```bash
npm install
npm run dev       # 开发服务器（默认 http://localhost:5173/）
npm run build     # 类型检查 + 生产构建
npm run preview   # 预览生产构建
npm test          # Vitest 单元测试（解析、协方差、投影、排序）
```

## 操作

- 左键拖动：旋转视角；右键拖动（或双指）：平移；滚轮：缩放（OrbitControls）。
- 工具栏可重新载入内置场景、打开本地 `.splat`、适配全景、重置视角。
- 左下角 HUD 显示高斯总数、当前可见数量与加载/错误状态。
- 窗口尺寸或设备像素比变化时自动更新画布与投影比例。

## 镜头编排与导出

右侧「镜头编排」面板用于制作重建场景展示短片，浏览能力始终保留：

1. 用自由浏览（轨道控制）调整好第一个视角，点击「记录当前镜头」建立首帧
   （首帧时间固定为 0 秒）。
2. 继续移动相机，再次「记录当前镜头」会在末尾追加关键帧（默认时间 +1s）。
3. 每个关键帧可直接修改时间（秒）、「更新姿态」为当前相机、或「删除」。
   首帧必须为 0，后续时间必须严格递增；位置/四元数非有限数值、四元数为零或
   垂直视场角超出 1°~170° 都会在面板提示并拒绝，已有轨道不会被破坏。
4. 至少两帧后可拖动时间轴预览，或点击「播放 / 暂停」。预览采样与导出采样
   共用同一套逻辑：位置与垂直视场角线性插值，旋转走最短弧球面插值
   （slerp）；播放到终点时停在末帧姿态。轨道控制只在自由浏览时生效，
   不会覆盖关键帧相机，「返回自由浏览」可随时回到编排前的相机姿态。
5. 点击「导出 1280×720 VP8/WebM」进行**离线**成片：按 30fps 从 0 开始
   固定步长取样（取样时刻严格小于末帧时间，末尾不足一帧时最后一样本取
   剩余时长，成片时长与镜头时长一致、无音轨）。每一帧都会等待该相机姿态
   的高斯排序与绘制完成后再送入编码器，不是录制实时播放，也不会在内存中
   积存整段原始帧。
6. 导出期间显示已完成帧数/进度，可随时「取消导出」；场景与轨道保持不变。
   成功后自动下载可独立播放的 `.webm`；失败或取消不会产生残缺文件，编码/
   封装资源会被释放，画布尺寸与原相机姿态恢复，可再次导出。

镜头相关代码按业务模块拆分：

- `src/cinematic/track.ts`：关键帧数据模型、校验（时间严格递增、数值与 FOV
  范围）、最短弧 slerp、线性位置/FOV 采样与导出固定步长时间表。
- `src/cinematic/playback.ts`：基于 `requestAnimationFrame` 的时间轴播放时钟，
  拖动、播放与导出共用 `sampleTrack`。
- `src/cinematic/exporter.ts`：mediabunny（WebM + VP8，WebCodecs 编码）离线
  渲染-等待-编码逐帧管线、进度与取消、资源释放。
- `src/viewer/SplatViewer.ts`：镜头/自由浏览模式切换、姿态采集与应用、
  固定像素尺寸离线渲染并等待匹配排序结果绘制完成。
- `src/ui/TimelinePanel.tsx`：关键帧编辑、时间轴、播放、导出进度界面。

## `.splat` 文件格式

每条记录固定 32 字节，小端字节序：

| 偏移 | 字节数 | 内容 |
| --- | --- | --- |
| 0 | 12 | Float32 位置 `x, y, z` |
| 12 | 12 | Float32 三轴正尺度 `sx, sy, sz` |
| 24 | 4 | Uint8 颜色 `R, G, B, A`（固定 RGB，不做 SH 计算） |
| 28 | 4 | Uint8 四元数 `w, x, y, z` |

四元数解码：每个字节先减 128 再除以 128，然后整体归一化。

解析会逐条校验并在以下情况下整体拒绝（抛出错误、不覆盖当前场景）：

- 文件长度不是 32 的整数倍（截断）或为空；
- 位置/尺度包含非有限值（NaN、±Infinity）；
- 任一尺度不为正（`<= 0`）；
- 四元数为零（无法归一化）。

## 渲染管线

代码按职责拆分：

- `src/splat/parser.ts`：严格解析与包围体计算。
- `src/splat/covariance.ts`：四元数旋转矩阵、世界协方差 `R S (R S)^T`、相机变换与透视雅可比 EWA 屏幕投影（含 0.3 像素低通滤波）。
- `src/renderer/SplatRenderer.ts`：WebGL2 实例化（`drawArraysInstanced`）椭圆四边形，片元按逆协方差二次型计算高斯透明度；支持按精确像素尺寸（dpr=1）离屏渲染导出，避免宽屏导出时横向拉伸。
- `src/splat/frameBuilder.ts`：逐高斯投影、剔除、按相机空间深度排序、打包 24 字节/实例的属性数据。
- `src/splat/splat.worker.ts` 与 `src/splat/messages.ts`：在 Web Worker 中执行投影排序，保持主线程交互响应。
- `src/viewer/camera.ts`：由 Three.js 透视相机导出像素焦距/主点与包围球适配。
- `src/viewer/SplatViewer.ts` 与 `src/viewer/SplatWorkerClient.ts`：交互编排、任务节流、状态一致性与资源释放。
- `src/ui/*`：React 界面（加载、文件选择、HUD、错误提示）。

### 排序与一致性

- Worker 每次按当前视图矩阵把高斯变换到相机空间，剔除后按正深度**从远到近**排序，再传回主线程；WebGL2 使用预乘 alpha 的 `gl.blendFunc(ONE, ONE_MINUS_SRC_ALPHA)` 正确混合。
- 同一时刻只允许一个排序任务在途：相机连续变化时只发送最新位置，Worker 不会堆积过期相机任务，主线程也只接受“当前场景 + 最新帧号”的结果，连续转动或快速切换文件时迟到结果不会覆盖新状态。
- 迟到帧（旧场景或旧相机位置）在绘制前即被整体丢弃，且不会误触发等待者；导出时每个离线渲染都等待**对应帧号**的排序结果绘制完成后才编码。
- EWA 雅可比使用正确的透视偏导符号（`du/dtz = fx·tx/d²`、`dv/dty = -fy/d`），离轴各向异性高斯的屏幕椭圆方向不再镜像翻转。
- 切换场景使用单调 `sceneId`；卸载时终止 Worker 并删除 GL 缓冲、VAO 与程序。

### 剔除与渲染取舍

- 相机后方、深度未越过近裁面（`near * 1.05`）的高斯直接剔除：透视雅可比在相机附近发散，否则会产生铺满屏幕的异常椭圆。
- 屏幕协方差非正定、椭圆半径过大（超过 2 倍屏幕边长）或完全在视口外的高斯剔除；半径小于 0.5 像素的亚像素高斯跳过。
- 每个高斯用其屏幕协方差最大特征值生成 3σ 椭圆四边形（不是等大点、球体或贴图），片元着色器按逆协方差计算椭圆高斯，`alpha < 1/255` 的片元丢弃。
- 仅使用文件内固定 RGB 与 alpha，不使用球谐高频颜色，也不做 Tonemap/色调编辑。
- 每帧在 CPU（Worker）端构建屏幕协方差并排序，精度与正确性优先；9 万级高斯在现代桌面浏览器可交互，超大场景可后续再做分块/瓦片化。

## 测试

`npm test` 覆盖：解析成功路径与截断、非有限值、非正尺度、零四元数拒绝；四元数矩阵、轴对齐协方差、EWA 投影中心点、各向同性与**离轴雅可比符号**、近裁面/后方剔除；远到近排序顺序与实例打包字段；以及镜头轨道的关键帧时间规则、非法数值/FOV 拒绝且不破坏原轨道、最短弧 slerp、线性采样、终点钳制和 30fps 固定步长导出时间表（含末尾不足一帧的剩余时长）。
